# 💀 Deadpool V7

WhatsApp bot by **Confronter** — Baileys multi-device.

## Features
- Auto view / like status, auto-react
- Anti-delete & anti-viewonce (pm/chat)
- Welcome / goodbye, antilink
- Stickers, play (MP3), video (MP4), TikTok, IG, YT
- Group tools, owner broadcast, expiry license
- Boxed menu + rotating text styles + video menu
- Footer: Powered by + day/date on every reply

## Setup
```bash
npm install
npm run pair   # pairing code = DEADPOOL → get deadpool~ session
```
